# СтопДЕП

Расширение и сайт проекта.

- extension — распакованное расширение Chrome / Edge.
- docs — сайт и ZIP расширения для скачивания.
- scripts/seo.cjs — сборка canonical, sitemap и метаданных для настоящего адреса сайта.

## GitHub Pages

1. Загрузи содержимое этой папки в новый репозиторий, включая .github.
2. В Settings → Pages выбери Source → GitHub Actions.
3. Отправь изменения в main. Workflow опубликует docs и подставит адрес GitHub Pages.
4. После публикации добавь сайт в Google Search Console и Яндекс Вебмастер. Отправь sitemap.xml.

Если используешь свой домен, настрой его в Pages перед следующим запуском workflow.
На project Pages robots.txt находится внутри пути репозитория. Корневым robots управляет сайт аккаунта или собственный домен.

Появление в поиске зависит от обхода и решения поисковых систем.
